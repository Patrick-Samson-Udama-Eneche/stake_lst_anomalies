# Geospatial inputs

The files here are listed, with their source, terms and the code that reads them, in the main
[README](../../../README.md#data-in-this-repository) under *Data in this repository*.

`OSM_features.ipynb` is the notebook we used to make the OpenStreetMap extracts in the `City_*` folders. We keep it
as the record of how they were made. It expects an older folder layout, so it does not run as it is, and no
other code reads these extracts: Notebook 01 downloads the OpenStreetMap features it needs.
